# Official DIO/ODI brand assets

The SVG files in this directory are copied unchanged from the canonical brand asset directory in [dan-beranek/dio-odi-autorsky-koncept](https://github.com/dan-beranek/dio-odi-autorsky-koncept/tree/main/assets/brand). They must not be redrawn, approximated, recolored, or geometrically modified for this project.

The primary shared mark is `logo-dio-odi.svg`; use `logo-dio-odi-inverse.svg` on a dark surface. The standalone symbol variants are provided for compact contexts. The shorter DIO wordmark is retained as an official asset but is not the default identity for this project.

The symbol has five outer nodes, one central node, and ten displayed connections. It is not a complete K6 graph. Do not substitute a newly generated illustration for the canonical SVG.
